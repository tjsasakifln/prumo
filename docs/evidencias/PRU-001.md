# PRU-001: fundação executável

## Escopo demonstrado

Interface e servidor MCP são executáveis Rust, com o domínio compartilhado, projeto local versionado e gravação por revisão. A UI é também compilável como componente WASM. A decisão do framework e limites estão no [ADR](../adr/0001-aplicacao-rust.md). Não há cálculo estrutural ou de instalações.

## Matriz de aceitação

| Critério | Código e prova reproduzível |
|---|---|
| Criar, salvar e reabrir projeto pela UI | `apps/prumo-desktop/tests/ui.rs`: cliques em widgets reais via AccessKit, reinício de Desktop e conferência das identidades |
| UI e MCP operam o mesmo projeto | `actual_ui_save_restart_mcp_modify_and_ui_reopen_preserve_identity`, cliente rmcp e servidor em processo separado |
| MCP negocia revisão suportada e rejeita desconhecida | `unknown_version_and_missing_request_metadata_are_rejected`, cliente JSON independente, perfil 2026-07-28 |
| Acesso básico desde a primeira operação | ReadOnly por padrão; `readonly_is_enforced_for_unadvertised_mutations_and_creation` testa todas as mutações e criação |
| Sem caminhos livres, shell ou SQL | Catálogo fechado; schemas estritos, teste de campos extras, nomes desconhecidos e parâmetros maliciosos |
| Identidade, unidades, revisão e autoria | Testes do serviço e domínio; metros canônicos, IDs físicos/analíticos distintos, histórico persistido |
| Contratos de instalações extensíveis | Ambientes, nove disciplinas incluindo estruturas, redes, portas e conexões tipadas, extensões persistidas |
| Entrada inválida não danifica projeto | Bytes anteriores preservados; comprimentos nulos, números não finitos, corrupção e schema futuro recusados |
| Toolchain e dependências fixadas | Cargo.lock e rust-toolchain.toml1.99.1; CI Windows/Linux com fmt, Clippy, testes e build `--locked` |
| Reaproveitamento web | `cargo check -p prumo-ui --target wasm32-unknown-unknown --locked`; não representa distribuição de aplicativo web |
| Reuso e licenças examinados | [Ficha de componentes](../componentes/PRU-001.md), inventário e avisos distribuídos |

## Revisão independente

A revisão de código separada das implementações identificou e fez corrigir leitura em pasta sem escrita, destino digitado diferente do projeto carregado, erro de arquivo corrompido inicialmente oculto e nomes acessíveis dos campos de coordenadas. Cada correção tem teste pertinente. O ensaio UI/MCP foi ampliado para operar efetivamente os widgets antes de iniciar o servidor em outro processo.

## Reprodução

Os comandos estão em [DESENVOLVIMENTO.md](../DESENVOLVIMENTO.md). Os detalhes dos 16 testes iniciais de domínio/serviço e sete testes de protocolo estão nas fichas [core](PRU-001-core.md) e [MCP](PRU-001-mcp.md). A UI acrescenta quatro testes de comportamento, totalizando 27 testes na primeira integração. A execução de CI associada à PR conserva o compilador, a resolução transitiva, os resultados Windows/Linux e o código exato testado.

## Limites explícitos

O arquivo desta etapa contém JSON nativo versionado, com substituição atômica e bloqueio entre escritores. O pacote transacional completo, backup e recuperação pertencem à PRU-005. O servidor é stdio local e não anuncia HTTP ou transporte legado. A acessibilidade foi exercitada pela árvore e ações AccessKit, sem declarar campanha com leitores de tela ou usuários concluída. Impressão, instalador comercial e motores pertencem às suas etapas.
